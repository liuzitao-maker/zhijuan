# 仓库推送指引（GitHub 优先 / Gitee 备选）

> 比赛接受 GitHub 或 Gitee 的 **Public** 仓库。
> 当前本机已配置 GitHub 远程：`https://github.com/liuzitao-maker/zhijuan.git`

---

## 方案 A：GitHub（推荐，你已登录）

### 1. 创建空仓库（30 秒）

打开预填链接：**https://github.com/new?name=zhijuan&visibility=public**

确认：
- Repository name = `zhijuan`
- 可见性 = **Public**
- Add a README / .gitignore / license **全部不勾**
- 点 `Create repository`

### 2. 推送

远程已配置好，在项目目录执行一条命令即可：

```powershell
cd "C:\Users\刘子韬\Documents\deepseek-harness\default-workspace\zhijuan"
git push -u origin main
```

> 首次推送会弹出 GitHub 授权窗口（git-credential-manager），点 `Authorize` / 登录即可。
> 本机 `credential.helper = manager`，无需手动输入 Token。

### 3. 验证

打开 `https://github.com/liuzitao-maker/zhijuan`，确认：

- [ ] 未登录（无痕窗口）也能访问 → 公开仓库
- [ ] README 正常显示，含 4 张界面预览
- [ ] 提交历史 **40+ 条**（不是一次性提交）
- [ ] 文件列表里**没有** `server/.env`

---

## 方案 B：Gitee（备选）

1. 打开 https://gitee.com/projects/new
2. 仓库名 `zhijuan`，选**公开**，不勾任何初始化文件
3. 改远程并推送：

```powershell
cd "C:\Users\刘子韬\Documents\deepseek-harness\default-workspace\zhijuan"
git remote set-url origin https://gitee.com/<你的Gitee用户名>/zhijuan.git
git push -u origin main
```

> Gitee 需用「私人令牌」代替密码：头像 → 设置 → 私人令牌 → 生成 → 勾选 `projects`。

---

## 兜底：如果两种都推不上去

```powershell
cd "C:\Users\刘子韬\Documents\deepseek-harness\default-workspace"
git -C zhijuan bundle create zhijuan.bundle --all
```

`zhijuan-源码与提交历史.bundle`（已在工作区根目录，4.8MB）包含完整提交历史，
可在任意机器上 `git clone zhijuan-源码与提交历史.bundle zhijuan` 还原。

比赛明确要求公开仓库链接，因此**优先解决推送**，打包只作为时间不够时的兜底。
