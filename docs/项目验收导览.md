# 项目验收导览（5 分钟看懂）

## 0. 打开方式

服务已经在跑，直接打开浏览器访问：

**http://localhost:5173**

> 如果打不开，在项目目录 `C:\Users\刘子韬\Documents\deepseek-harness\default-workspace\zhijuan` 执行 `npm run dev`。

---

## 1. 工作台（首页）

**看什么**：四张指标卡（已生成试卷 / 完成作答 / 平均正确率 / 覆盖知识点）、最近作答、知识点掌握度雷达图、最近试卷。

**为什么这样设计**：这是「学情总览」的入口，让用户一眼知道自己的练习状况，而不是每次从零开始。

---

## 2. 新建试卷（核心页面，重点看这里）

**操作**：
1. 点左侧「新建试卷」
2. 点一个快捷模板（例如「函数极限与连续」）
3. 点「生成试卷」，**然后盯着右侧面板**

**看什么**：
- 右侧不是转圈动画，而是一条**逐步生长的流水线轨迹**
- 会依次出现：出题 Agent 生成 → 本地结构校验 → 独立审题 Agent 交叉复核
- 如果审题发现问题，会出现红色的「复核未通过」条目，然后自动进入「修复」轮次
- 每条轨迹都带耗时与状态颜色

**这是整个项目最值钱的地方**：把一个本来黑箱的 AI 生成过程，变成了可见、可审计的流程。

---

## 3. 试卷作答

生成完成后点「开始作答」。

**看什么**：
- 试卷是米白纸张质感 + 衬线字体，数学公式由 KaTeX 实时渲染
- 单选点选项、多选可多选、填空/简答可直接输入
- 底部固定条显示作答进度

随便答几题（不用全对），点「提交并批改」。

---

## 4. 学情报告

**看什么**：
- 左侧大圆环：得分与正确率
- 知识点雷达图：哪个知识点最薄弱一目了然
- 逐题明细：每题的得分、你的答案、正确答案、错因说明
- 紫色框：AI 生成的学情诊断（明确指出最薄弱点 + 下一步建议）
- 页面最下方：完整解析

---

## 5. 试卷库

**看什么**：
- 卡片式试卷列表，标注学科、难度、是否审题通过
- 点进任意一份试卷，页面右上角有「查看流水线记录」——**可以回溯这份试卷生成时两个智能体做了什么、被打回了多少次**

这个功能是「过程可复现」的直接体现。

---

## 6. 命令行验证（可选）

在项目目录执行：

```
node scripts/smoke.mjs
```

会不打开浏览器地跑完「生成 → 审题 → 作答 → 批改」全链路，并打印每一轮的耗时与 token。

还可以跑多学科回归：

```
node scripts/check-robustness.mjs
```

---

## 7. 已知限制（如实说明）

| 限制 | 影响 | 后续方案 |
|---|---|---|
| 简答题批改有 ±1 分波动 | 边界答案分数不完全稳定 | 引入参考答案向量匹配 |
| 题库未沉淀 | 同一知识点可能重复出题 | 生成结果入库 + 去重 |
| JSON 文件存储 | 不支持多用户并发 | 换 SQLite/Postgres |
| 题目不能手动编辑 | 无法微调分值或替换选项 | 增加教师端编辑 |
