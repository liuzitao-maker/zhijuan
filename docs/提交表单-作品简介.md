## 三、作品简介（300 字版，用于表单正文）

**智卷**是一个面向高校教学的 AI 智能出卷与批改引擎。教师只需输入学科与知识点，系统即可在十余秒内生成一份包含单选、多选、填空、简答四种题型、带解析、可直接在线作答的试卷；学生作答后，客观题由确定性代码判分，简答题由阅卷智能体按评分要点给分，最终输出知识点掌握度雷达图与学情诊断。

项目的核心创新是**双智能体互检流水线**：出题智能体与独立审题智能体的上下文完全隔离，审题者被设定为「敌对视角」，默认假设试卷有问题，逐题核算答案、检查超纲与歧义；发现问题后以问题清单回灌给修复智能体，形成带反馈边的闭环，最多两轮。

为控制成本与保证收敛，系统在模型之间插入了一道**确定性的本地结构校验**，并用算术方式自动归位分值——能算清楚的地方绝不交给模型。整个流水线每一步都以 SSE 实时推送到前端，生成过程完全可见、可审计。

项目使用 React + TypeScript + Node.js 全栈实现，刻意不引入数据库与 UI 框架，任何人克隆仓库、填入 API Key、执行 `npm run dev` 即可在十分钟内复现完整闭环。

## 四、核心创新点（用于答辩/评审说明，3 条）

### 1. 双智能体互检：用结构对抗模型的自洽偏差
单一模型既出题又审题时，几乎必然判定「这份试卷很好」。项目把生成与审查拆成两次完全独立的模型调用（不同提示词、不同上下文、温度 0.85 / 0.15），审查者看不到生成者的推理过程，只能面对最终产物逐题核算。

### 2. 验证比生成便宜：把能算的交给代码
- 结构合法性（题型、选项、答案是否在选项内、解析是否存在）由确定性代码校验；
- 分值加总属于算术问题，由归一化阶段直接补齐，不占用模型修复轮次；
- 批改阶段只有简答题调用模型，客观题全部由代码判分。

### 3. 可解释的收敛策略：给反馈环装闸门
- 三级严重度定义（blocker / major / minor）写死在提示词中；
- 第 1 轮 blocker 与 major 均阻断，第 2 轮起仅 blocker 阻断，避免审题者不断提出新的风格建议导致永不收敛；
- 超限则降级交付并显式标记「待人工复核」，保证用户永远拿到产物。

## 五、技术栈

| 层次 | 技术 |
|---|---|
| 前端 | React 18、TypeScript、React Router 6、KaTeX、原生 CSS 设计系统 |
| 后端 | Node.js、Express 4 |
| 模型 | DeepSeek Chat（OpenAI 兼容协议，可替换） |
| 流式通道 | Server-Sent Events（POST + ReadableStream 手工解析） |
| 持久化 | JSON 文件（为保证复现速度刻意不用数据库） |

## 六、适用场景

1. **教师随堂测验**：选定章节知识点，一分钟内得到一份可直接打印或在线发布的测验。
2. **学生定向练习**：针对薄弱知识点反复出题，答完立刻拿到错因与下一步建议。
3. **自学自测**：输入任何学科知识点，快速形成可量化的掌握度评估。

## 七、可复现性说明（评委快速验证）

```bash

npm install

npm run dev                       # 打开 http://localhost:5173
```
